# Git Diff

在 VS Code 中查看文件历史、追踪某行的改动，或比较两个分支、两个提交。比较结果使用 VS Code 原生 Diff 编辑器，可沿用当前主题和 Diff 设置。

## 使用方式

可以从活动栏的 **Git Diff**、命令面板（搜索 `Git Diff`）或编辑器右键菜单进入。

| 功能 | 操作 |
| --- | --- |
| 文件历史 | 打开 **Git Diff** 侧栏，历史默认跟随当前文件。也可在资源管理器中右键文件查看历史。历史能追踪 Git 识别出的重命名。单击某个提交，比较它与父提交的文件版本。 |
| 行历史 | 运行一次 **行历史** 切换模式。历史会跟随当前文件、光标所在行或连续选区。单击历史条目，打开该次提交的文件 Diff 并定位到改动行。 |
| 比较分支 | 运行 **比较分支**，依次选择左侧基准分支和右侧目标分支。支持本地分支及本地已有的远程跟踪分支。 |
| 比较提交 | 运行 **比较提交**，依次输入完整或唯一的短提交 ID，也可在最近提交列表中选择。 |

每次比较都会打开一个独立的 VS Code 多文件 Diff 标签页。可以同时保留多组比较，在编辑器标签页之间切换。**比较**侧栏按组列出变更文件和状态，单击组名可打开整组 Diff，单击文件可查看单独的 Diff。比较方向为左侧基准 → 右侧目标。

分支有新提交后，点击标签页右上角或侧栏对应组的 **刷新本次比较**，即可重新计算该组的差异。刷新读取本地 Git 中的分支和远程跟踪分支，远程更新可先通过 VS Code 的 **Git: Fetch** 获取。点击编辑器标签页的关闭按钮，或侧栏对应组的 **关闭本次比较**，只会移除这次比较结果。

历史视图可见时才自动刷新。打开历史 Diff 时会保留当前结果，返回工作文件后继续跟随。点击历史视图标题栏的 **文件历史** 可切回文件模式。

文件和行历史从当前仓库的 `HEAD` 开始。行历史会把当前文本中的行映射到 `HEAD`，新增且没有对应提交行的内容需要先提交。二进制变更在 Diff 中以文件大小和内容摘要显示。

## 本地运行

需要 VS Code 1.90 或更高版本，以及 `git` 命令。

```sh
npm ci
npm test
npm run package
```

开发时可在项目中按 `F5` 打开扩展开发宿主。打包生成的 `.vsix` 可通过 VS Code 的 **从 VSIX 安装…** 安装。
